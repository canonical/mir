## What's new in [Mir 2.32.0](https://github.com/canonical/mir/releases/v2.32.0)

Miroil updates from the Lomiri development team include support for keyboard events via `dispatch_input_event()` and a new `BasicTextInputHub` for compositors using Input Method Editors themselves.

Mir's SSD implementation now supports customizing the appearance of server-side decorations, including colors and metrics. See {ref}`customizing-server-side-decorations` for details.

The positioner adjustment algorithm has been improved to better handle cases where the initial positioner placement is outside the application zone. See {ref}`positioner-adjustment` for details.
